# 龙门产业沙盘 · longmen-simulator

龙门是年接待游客约为常住人口二十五倍的县域。这一页把它的山、温泉、民宿、年桔与功能膜产业铺成十个页面，看它在大湾区里靠什么位置吃饭。

单文件离线运行，双击即开。

## 打开方式

下载仓库后用浏览器打开 `index.html`；或本地起服务 `python3 -m http.server 8000`。不需要安装依赖，不上传数据。

## 十个页面

| 页面 | 文件 | 看什么 |
|---|---|---|
| 今日话题 | `index.html` | 公开渠道每日刷新的近况，按关注度排序，可分类、可刷新 |
| 各镇吃喝玩乐 | `town.html` | 11 个镇街乡的吃玩卡片与按月切换的当季农品 |
| 关系网 | `network.html` | 南昆山、永汉民宿、温泉、广深客源、年桔等主体依次生长，看龙门在湾区的连接 |
| 基本面 | `who.html` | 2025 年三次产业、两处方向不一致的地方、2026 年目标轨道 |
| 五条路 | `choices.html` | 五条发展路径可开可关，成对比较结果 |
| 未来 | `future.html` | 固定起点的重复运行，给出三档结果与达标比例 |
| 风洞测试 | `windtunnel.html` | 四个滑块：盘山通道中断、功能膜达产、投产延迟、过夜率，看结果怎么变 |
| 被忽略的发现 | `blindspot.html` | 五处容易被忽略的地方，老百姓的日子与目标其实是同一批事 |
| 一页报告 | `report.html` | 自动生成的图文汇总，含数据来源与使用限制 |
| 结语 | `ending.html` | 为什么要把话说清楚，以及后续方向 |

## 龙门的底数（公开统计）

| 指标 | 数值 |
|---|---|
| 常住人口 | 35.31 万 |
| 年接待游客 | 约 905 万人次（约为常住人口的 25 倍） |
| 功能膜新材料 | 68 宗项目、约 140 亿元投资、620 条涂布线 |
| 2026 规上工业目标 | 150 亿元（2025 年实际增 5.1%） |
| 龙门农民画 | 国家级奖项 41 个 |

## 数据来源

全部来自公开渠道：龙门县人民政府门户、统计公报与计划执行报告、文旅与农业公开信息、南方+ / 惠州日报，以及微博 / 抖音 / 头条公开热榜。页面标注来源与时间。

今日话题与各镇页不展示平台后台的阅读、转发、点赞与"想去"人数（公开渠道拿不到），改用分档表示，并标注更新时间。

## 边界

不预测具体产值或招商成败；页面上的结果是特定条件下的相对呈现，不是现实结论。不构成投资建议，不替代任何官方决策。
