# 龙门产业决策风洞

大湾区的生态后花园——用公开数据，把龙门的未来反复跑一万遍。

## 这是什么

一个开源的县域产业决策模拟器。不是预测，是**风洞**：把龙门的五条发展路径、各种压力场景，放进同一个模型里反复跑，看2030年GDP可能落在哪。

- 基期：217.6亿（2025）
- 2030参考目标：330亿
- 五条路：南昆山民宿升级 / 生态农业品牌 / 康养温泉旅游 / 融深融穗通道 / 低碳新能源
