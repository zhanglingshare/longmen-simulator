# 龙门产业决策风洞

大湾区的生态后花园——用公开数据，把龙门的未来反复跑一万遍。

## 这是什么

一个开源的县域产业决策模拟器。不是预测，是**风洞**：把龙门的五条发展路径、各种压力场景，放进同一个模型里反复跑，看2030年GDP可能落在哪。

> **口径说明**：模型基线中位数约330亿，是五条路径增量参数（合计约112亿）加基期217.62亿的设定结果，**不构成对路径可行性的证明**；它只回答"在这组假设下结果如何分布"。风洞页的中断天数、功能膜达产进度与投产延迟会真实进入模型、改变结果分布。"一张床"（留不住游客过夜）目前是**待验证核心假设**：硬数为25.5倍人次比、客单价-1.75%、永汉客单价-7.29%；过夜人次/住宿率/停留天数尚缺，需补证据，不以客单价下降直接推断住宿减少。

- 基期：217.6亿（2025）
- 2030参考目标：330亿
- 五条路：一张床·南昆山留宿 / 功能膜新材料 / 温泉康养 / 生态农业品牌 / 融深融穗通道
